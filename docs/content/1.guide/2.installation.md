# Installation

## Voraussetzungen

- [Bun](https://bun.sh) >= 1.1.0
- [Node.js](https://nodejs.org) >= 22 (Fallback-Runtime)
- Git

## Repository klonen

```bash
git clone https://github.com/Prachtkater/openpress.git
cd openpress
```

## Abhaengigkeiten installieren

OpenPress verwendet **Bun Workspaces** fuer das Monorepo-Management.

```bash
bun install
```

## Playground starten

Die Entwicklungsumgebung inklusive Visual Editor:

```bash
bun run dev
```

Der Playground ist unter `http://localhost:3000` erreichbar.

## Projekt-Struktur

```text
openpress/
  packages/
    core/           # Nuxt Module, HMR, Git-Storage Bridge
    ui/             # Op-Komponenten & Theme Engine
    schemas/        # Zod Schema-Definitionen
    poc-storage/    # POC 1: Git-backed JSON Storage
    poc-editor/     # POC 2: Glow-Frame UI Prototyp
    theme-tailwind-plus/        # Tailwind CSS Theme
    theme-material-expressive/  # Material Design 3 Theme
    feature-contact-form/       # Feature: Kontaktformular
    feature-booking/            # Feature: Buchungssystem
  playground/       # Nuxt Dev-Umgebung
  docs/             # Diese Dokumentation (Docus)
```

## Tech Stack

- **Framework**: [Nuxt 3](https://nuxt.com)
- **Runtime**: [Bun](https://bun.sh)
- **Styling**: Tailwind CSS (CMS UI) & Theme-basiert
- **UI Components**: [Nuxt UI](https://ui.nuxt.com)
- **Schemas**: [Zod](https://zod.dev)
- **Editor**: [Tiptap](https://tiptap.dev)
- **IDs**: [ULID](https://github.com/ulid/spec)
