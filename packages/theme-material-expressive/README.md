# @openpress/theme-material-expressive

Theme basierend auf Google Material Design 3 - Expressive.

## Ziel

- Material Design 3 "Expressive" Styling fuer alle Core-Bloecke
- Dynamic Color: Theme-Generierung aus Primaerfarbe
- Material Motion: Smooth Transitions und Animationen
- Responsive Design mit Material Breakpoints
- Component-Tokens fuer granulare Anpassung
- Section-Templates im Material-Stil

## Design-Prinzip

Implementiert die Material Expressive Design-Sprache.
Gleiche Block-Logik, voellig anderes visuelles Erlebnis als Tailwind Plus.
