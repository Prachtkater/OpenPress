# Getting Started

Welcome to the OpenPress Developer Documentation. OpenPress is a Nuxt-native Visual CMS with Git-backed storage.

## Quick Start

::steps
### Clone the repository
```bash
git clone https://github.com/openpress/openpress.git
cd openpress
```

### Install dependencies
We use **Bun** for lightning-fast package management and monorepo orchestration.
```bash
bun install
```

### Run the playground
Start the development environment including the Visual Editor.
```bash
bun run dev
```
::

## Project Structure

OpenPress is organized as a monorepo under the `packages/` directory:

- `core/`: The Nuxt module, HMR logic, and Git-storage bridge.
- `ui/`: Core components (`OpProvider`, `OpSection`, `OpSlot`) and theme engine.
- `schemas/`: Zod schemas for pages, site config, and features.
- `docs/`: This documentation site (powered by Nuxt UI Pro).

## Tech Stack

- **Framework**: [Nuxt 4](https://nuxt.com)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) (CMS UI) & Tailwind v3/v4 (Themes)
- **Runtime**: [Bun](https://bun.sh)
- **UI Components**: [Nuxt UI](https://ui.nuxt.com)
