# Themes

OpenPress trennt Logik (Features) und Visuals (Themes) strikt. Themes liefern ausschliesslich CSS-Klassen und visuelle Regeln.

## @openpress/theme-tailwind-plus

Theme basierend auf Tailwind CSS. Liefert Klassen-Mappings fuer alle Core-Bloecke im Tailwind-Stil.

### Struktur

```
src/
  index.ts                  # Theme-Export + Registration
  components/
    section.ts              # OpSection Klassen
    slot.ts                 # OpSlot Klassen
    blocks/
      rich-text.ts          # Rich-Text Block-Klassen
      image.ts              # Image Block-Klassen
      button.ts             # Button Block-Klassen
  tokens.css                # CSS Custom Properties
```

### Beispiel: Section Theme

```typescript
export const section: OpComponentTheme = {
  slots: {
    root: 'relative',
    inner: 'mx-auto max-w-7xl',
  },
  variants: {
    type: {
      hero: {
        root: 'overflow-hidden min-h-[60vh] flex items-center',
        inner: 'px-6 py-24 sm:py-32 lg:px-8',
      },
      features: {
        root: 'bg-gray-50 dark:bg-gray-900/50',
        inner: 'px-6 py-24 sm:py-32 lg:px-8',
      },
      cta: {
        root: 'bg-primary-600 dark:bg-primary-500',
        inner: 'px-6 py-16 sm:py-20 lg:px-8 text-center text-white',
      },
    },
  },
}
```

## @openpress/theme-material-expressive

Theme basierend auf Google Material Design 3 — Expressive.

- Material Design 3 "Expressive" Styling fuer alle Core-Bloecke
- Dynamic Color: Theme-Generierung aus Primaerfarbe
- Material Motion: Smooth Transitions und Animationen
- Responsive Design mit Material Breakpoints
- Component-Tokens fuer granulare Anpassung
- Section-Templates im Material-Stil

### Design-Prinzip

Implementiert die Material Expressive Design-Sprache. Gleiche Block-Logik, voellig anderes visuelles Erlebnis als Tailwind Plus.

**Status**: Planung.

## Eigenes Theme erstellen

Ein Theme-Paket exportiert ein `OpThemeConfig`-Objekt:

```typescript
import type { OpThemeConfig } from '@openpress/ui'

export const theme: OpThemeConfig = {
  name: 'mein-theme',
  components: {
    section: { slots: { root: '...', inner: '...' }, variants: { /* ... */ } },
    slot: { slots: { root: '...', empty: '...' }, variants: { /* ... */ } },
    block: {
      'rich-text': { slots: { root: '...' } },
    },
  },
}
```

Themes registrieren sich selbst via Nuxt-Plugin:

```typescript
import { registerTheme } from '@openpress/ui'
registerTheme('mein-theme', () => import('./theme'))
```
