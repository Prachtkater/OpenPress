# @openpress/playground

Entwicklungs- und Test-Umgebung fuer OpenPress.

## Ziel

- Nuxt 3 App die alle OpenPress-Pakete einbindet
- Live-Reload waehrend der Entwicklung
- Test-Seiten mit verschiedenen Block-Kombinationen
- Theme-Switching zum Testen beider Themes
- Feature-Module aktivieren/deaktivieren
- Repraesentative Content-Struktur mit Beispieldaten

## Nutzung

```bash
bun run dev
```

Startet die Playground-App unter `http://localhost:3000`.
Editor-UI ist erreichbar unter `http://localhost:3000/_edit`.
