# @openpress/ui

Die visuelle Editor-UI von OpenPress - das "Glow-Frame" System.

## Ziel

- **Glow-Frame Overlay UI**: Visueller Rahmen um editierbare Bereiche
- Toolbar-Komponenten fuer Block-Aktionen (Move, Delete, Settings)
- Drag & Drop Handles fuer Block-Reordering
- Settings-Panels fuer Block-Properties
- Theme-agnostische Basis-Styles (funktioniert mit jedem Theme)
- Keyboard-Shortcuts fuer Editor-Aktionen

## Design-Prinzip

Die UI-Komponenten ueberlagern die gerenderte Seite (In-Context-Editing).
Sie sind strikt getrennt von den Content-Themes.
