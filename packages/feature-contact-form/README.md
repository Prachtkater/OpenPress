# @openpress/feature-contact-form

Kontaktformular-Feature fuer OpenPress.

## Ziel

- **Drag & Drop Formular-Builder** im Editor
- Feld-Typen: Text, Email, Telefon, Textarea, Select, Checkbox
- **Zod-basierte Validierung** (Client + Server)
- Submission-Handling: Email-Versand, Webhook, JSON-Storage
- Spam-Schutz: Honeypot + optionales Captcha
- Erfolgs-/Fehler-Meldungen konfigurierbar
- Theme-agnostisch: Styling kommt vom aktiven Theme

## Feature-Manifest

Registriert sich als OpenPress Feature-Modul mit eigenem Block-Typ (`op-contact-form`)
und Settings-Panel im Editor.
