# Media Library

Die OpenPress Media Library bietet einen zentralen Hub fuer die Verwaltung aller digitalen Assets. Sie ist driver-agnostisch konzipiert und unterstuetzt lokale Speicherung als Standard, waehrend Cloud-Integrationen wie Cloudinary moeglich sind.

## Features

- **Unified Interface**: Konsistente API fuer Datei-Operationen ueber verschiedene Storage-Backends
- **Visual Explorer**: Integrierter Datei-Browser fuer den OpenPress Editor
- **Smart Uploads**: Drag-and-Drop mit automatischer Metadaten-Extraktion
- **Driver System**: Plugbare Architektur fuer diverse Storage-Anforderungen

## Driver System

OpenPress nutzt einen driver-basierten Ansatz fuer Media-Storage.

### Local Driver

Speichert Dateien im `public/_openpress/media`-Verzeichnis. Diese Assets werden von Git getrackt und sind ideal fuer kleine bis mittlere Projekte, bei denen Content zusammen mit Code deployed wird.

### Cloud Drivers (Geplant)

Support fuer externe Provider wie **Cloudinary**, **S3** oder **Imgix** fuer High-Volume-Media und On-the-Fly-Transformationen.

## Verwendung

### In Komponenten

Die `OpImage`-Komponente rendert Assets und handhabt automatisch die Pfad-Aufloesung basierend auf dem aktiven Driver.


### Editor-Integration

Beim Editieren eines Blocks mit Bild- oder Datei-Feld wird der Media Picker Overlay ausgeloest:

1. **Selektion**: Bestehende Assets in der Library durchsuchen
2. **Upload**: Dateien direkt in den Picker droppen, um sie zum aktuellen Driver hochzuladen
3. **Metadaten**: Die Library extrahiert Dimensionen, Format und Groesse automatisch

Die Media Library ist erweiterbar konzipiert. Eigene Drivers koennen registriert werden, um benutzerdefinierte Storage-Backends zu unterstuetzen.
