# @openpress/feature-booking

Termin- und Buchungssystem fuer OpenPress.

## Ziel

- **Kalender-Widget** fuer Terminauswahl im Frontend
- Verfuegbarkeits-Management (Zeitfenster, Puffer, Blocker)
- Buchungsformular mit konfigurierbaren Feldern
- Bestaetigungs-Workflow: Email-Benachrichtigung fuer beide Seiten
- Optional: Integration mit externen Kalendern (Google, CalDAV)
- Admin-Uebersicht: Alle Buchungen im Editor-Dashboard
- Theme-agnostisch: Styling kommt vom aktiven Theme

## Feature-Manifest

Registriert sich als OpenPress Feature-Modul mit eigenem Block-Typ (`op-booking`)
und Dashboard-Seite unter `/_edit/bookings`.
